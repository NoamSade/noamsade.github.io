Hina Desktop – Privacy Policy

Last updated: 27 October 2026

Hina Desktop is a personal assistant used only by its owner, on the owner's own computer.

Data accessed

With the owner's consent, the app accesses the owner's Google account data: Gmail (read and create drafts), Google Calendar (read and create events), Google Drive, Docs and Sheets (read, and files the app creates), and Contacts (read).

How data is used

The data is used only to provide assistant features to the owner, such as schedule summaries, email triage and drafting. It is not sold, not used for advertising, and not shared with third parties except the AI service that processes the owner's own requests.

Storage

OAuth tokens and any cached data are stored locally on the owner's computer. No data is stored on servers operated by this app.

Google API Services User Data Policy

Hina Desktop's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
